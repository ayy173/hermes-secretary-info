Your data and this assistant

This notice covers the personal Hermes Secretary configuration operated by GitHub user ayy173.

Information accessed and why

With the operator’s authorization, Google access covers Gmail messages and settings, sending email, reading calendars and editing calendar events. The assistant uses relevant information to perform requested email summaries, prepare correspondence, plan meetings and carry out approved actions. It requests no Google Drive or Contacts access in this configuration.

Storage and retention

OAuth credentials and tokens are stored in the local Secretary profile, with file access restricted to the operating-system user. Relevant task content can also be stored in local conversation history, saved outputs or Jot notes. No automatic deletion period has been configured for those local records; the operator manages them. Computer backups may retain additional copies.

Processing and sharing

Google processes Google API requests. When Telegram is used, content sent through that channel is handled by Telegram and the configured gateway. The selected AI model processes the context supplied to it; a local model processes that context on the computer, while a cloud model sends it to the configured provider. The operator should review the selected provider’s terms before sending sensitive material. Delegated tasks can share relevant context with other configured assistants.

This personal configuration does not sell Google user data, use it for advertising or use it to train a generalized AI model. Google user data is used to provide the requested personal-assistant functions. Hermes Secretary’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. The operator must ensure future model, plugin and sharing choices remain consistent with this notice.

Control and deletion

The operator can revoke Google access at any time through Google Account connections. Revocation stops future authorized access but does not remove content already saved in chats, outputs, notes, sent messages or backups. Those copies must be managed separately in the relevant application. Turning off Jot AI collaboration blocks Jot’s own agent tools; it does not create an operating-system barrier against separately permitted file tools.

This information site

These are static information pages with no forms, advertising or analytics scripts. The chosen hosting service may process ordinary request metadata under its own privacy terms. These pages do not connect to Gmail or Calendar or receive OAuth credentials.

Operator and changes

Operator profile: github.com/ayy173. Do not send private data in public GitHub discussions. This notice must be updated when the configuration’s actual data practices change.
