Hermes Secretary

A personal assistant for correspondence drafts, meeting preparation and administrative follow-through.

This page describes one privately configured assistant running in Hermes on its operator’s computer. It is not a public registration service or an official product of Google, Telegram or the Hermes developers.

Google account access

When authorized by its operator, the assistant can read Gmail messages and settings, send email, read calendars and edit calendar events. These permissions support requested summaries, correspondence and scheduling tasks.

The assistant’s instructions require specific approval before sending messages or changing calendar events. This is a workflow instruction; the granted Google permissions themselves allow those actions.

Where it runs

The assistant runs on the operator’s computer. Telegram is an optional messaging channel. The active AI model and provider are chosen in Hermes; relevant task content can be processed by that provider when a cloud model is selected.
